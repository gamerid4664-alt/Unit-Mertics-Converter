## 🌐 Overview

**Metric / Imperial Unit Converter** is a simple web application that converts values between commonly used metric and imperial units.

The project focuses on practicing **JavaScript logic, DOM manipulation, event handling, input validation, and reusable functions** while building a functional application from scratch.

---

## ✨ Features

| Category      | Conversions        |
| ------------- | ------------------ |
| 📏 **Length** | Meter ↔ Feet       |
| 💧 **Volume** | Liters ↔ Gallons   |
| ⚖️ **Mass**   | Kilograms ↔ Pounds |

### Also includes

* 🔢 Numeric input handling
* ✅ Input validation
* ⚡ Instant conversion
* 🧩 Reusable JavaScript functions
* 📱 Responsive design
* 🎨 Clean user interface
* 🚫 Invalid-input error handling
